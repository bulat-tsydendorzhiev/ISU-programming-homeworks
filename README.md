Этот репозиторий содержит в себе домашние задания на языке Python курса "Программирование" из первого семестра ИГУ.

## Запуск тестов

Тесты лежат в `tests/` и повторяют структуру исходников из `src/`.

Установка зависимостей:

```bash
pip install -r requirements.txt -r requirements-dev.txt
```

Запуск всех тестов:

```bash
python -m pytest
```

Статус последниех тестов — бейдж выше.
